# Rabbid Shimeji Project

## Description
A fun Object-Oriented Programming project featuring a Shimeji character that bounces around your screen. This project demonstrates core OOP concepts including classes, objects, encapsulation, and inheritance.

## Features
- Interactive Shimeji character
- Bouncing animation
- Screen boundary detection
- Click to interact with the character

## Technologies
- **Language**: Python
- **Graphics Library**: Pygame
- **Concepts Demonstrated**: Classes, Objects, Encapsulation, Animation

## Project Structure
```
rabbid-shimeji-project/
├── README.md              # This file
├── shimeji.py            # Main Shimeji character class
├── game.py               # Game logic and main loop
├── requirements.txt      # Python dependencies
└── assets/               # Folder for images (optional)
```

## How to Run
1. Install dependencies: `pip install -r requirements.txt`
2. Run the game: `python game.py`
3. Watch your Shimeji bounce around!
4. Click on it to make it change behavior
